# 03: The MCP connector is a name, not a path

**Category:** enhancement
**Status:** ready-for-agent
**Blocked by:** none
**Blocks:** none

**What to build:** The installer adds its own program directory to the per-user `PATH`, and the MCP tab emits
`"command": "agentify-mcp"` instead of the absolute path. Uninstall removes the entry it added.

## Evidence

- `%LOCALAPPDATA%\Programs\Agentify` is absent from the user `PATH`.
- `shell_info()` builds the connector config from `mcp_binary()`'s absolute path, which is what the MCP tab shows.

## Agent Brief

> *This was generated by AI during triage.*

**Category:** enhancement
**Summary:** One per-user PATH entry exposes the installed directory, so the connector config names `agentify-mcp` instead of an absolute path.

**Settled decisions:**
- The same entry exposes both `agentify-mcp` and `agentify`.
- Install and uninstall are symmetric: only the entry the installer added is removed, and a user-edited PATH
  survives.

**Current behavior:**
The install directory is not on the user PATH, so the MCP tab's copy-paste config carries the full absolute path.

**Desired behavior:**
Install adds the program directory to the per-user PATH once and announces the change so new processes see it.
The MCP tab's config names `agentify-mcp` and keeps `AGENTIFY_HOME` in `env`; the tab says an already-running
client must restart to pick the entry up. Uninstall removes the entry it added, preserving surrounding entries
and the registry value's type. A development build never mutates PATH and keeps the absolute path.

**Key interfaces:**
- The per-user environment PATH value, preserving its type and ordering.
- The environment-change broadcast Windows uses to announce a PATH update.
- The shell's connector info: the command it reports and whether that command resolves.
- Installer hooks in both directions, tracking whether this install added the entry.

**Acceptance criteria:**
- [ ] A fresh install makes `agentify-mcp` and `agentify` resolvable in a newly started shell.
- [ ] Installing twice leaves exactly one entry.
- [ ] Uninstall removes only the entry the installer added, preserving other entries and the value's type.
- [ ] The MCP tab shows `"command": "agentify-mcp"` and still carries `AGENTIFY_HOME`.
- [ ] A development build does not mutate PATH and keeps the absolute path in its config.
- [ ] The tab states that an already-running MCP client needs a restart.

**Out of scope:**
- Registering the connector in any specific MCP client automatically.
- Changing the shim's stdio protocol or its tool list.
- Machine-wide (system) PATH changes.
