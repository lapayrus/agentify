# Agentify

A local, agent-native environment manager. Each Project runs in its own isolated runtime on the developer's machine, and one control plane exposes it to agents and humans alike.

## Agent skills

### Issue tracker

Issues live as markdown files under `.scratch/<feature>/`; the wayfinding map is `.scratch/<effort>/map.md`. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default triage roles. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/`. See `docs/agents/domain.md`.
