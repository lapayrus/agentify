The shape being tested

    

      
        
KeyRequiredRule

      
      
        
versionyes1

        
projectyeslower-case kebab; it becomes the URL namespace

        
secretsnoname → { generate: password|token } or { fromEnv: NAME }

        
resourcesyesmap of resource name → resource; at least one

        
resources.*.kindyesapp or database in v0

        
app.image / app.buildone ofexactly one, never both

        
app.commandnoarray of strings; no shell quoting

        
app.envnoliteral strings and ${secret:name} references

        
app.portsno{ port, hostname? }; hostname is required when a resource declares more than one

        
app.dependsOnnoresource names; start order, cycles rejected

        
app.healthcheckno{ port?, path?, interval? }; defaults to a TCP check on the first port

        
db.engineyespostgres in v0

        
db.credentialsyesusername plus a ${secret:name} password

        
db.volumenoname only; the daemon generates <project>-<resource>-data

        
any unknown field—rejected: typos fail loudly

version: 1
project: hello-pg

secrets:
  pg-password:
    generate: password
  api-token:
    fromEnv: HELLO_API_TOKEN

resources:
  web:
    kind: app
    build:
      context: .
      dockerfile: Dockerfile
    command: [node, server.js]
    env:
      DATABASE_URL: postgres://hello:${secret:pg-password}@db:5432/hello
      API_TOKEN: ${secret:api-token}
      GREETING: hello
    ports:
      - port: 3000
        hostname: web
    dependsOn: [db]
    healthcheck:
      port: 3000
      path: /health
      interval: 5s

  db:
    kind: database
    engine: postgres
    version: "16"
    credentials:
      username: hello
      password: ${secret:pg-password}
